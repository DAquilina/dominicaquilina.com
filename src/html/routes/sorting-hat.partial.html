The Animatronic Sorting Hat

Making Magic Real

The goal of this project was to build a working facsimile of the Sorting Hat from the Harry Potter franchise which could be used to announce table assignments to guests at my Harry-Potter inspired wedding. As a computer engineer with a background in both software development and circuit design, I was confident that I could build something which would both grant me the desired flexibility and outperform existing market solutions on my own.

Relevant Skills

  • Raspberry Pi: The Compute Module 3+ had mainstay power and a tiny footprint -- perfect for running and developing the code associated with this project! All code for the project was written natively using Notepad++ on PiOS, and the wiring was connected directly to the signal ports on the board.
  • Python: Python was chosen for this project because it was user-friendly to code in and had good native functionality for interfacing with hardware. The final result had three essential software components:
    • Audio Processing Library: I recorded custom sound bites for use in the app, and I needed a mechanism for having the jaw "say" those sounds. I came up with an algorithm to convert the amplitude of the sound wave into usable arrays of bits (1 indicating the jaw should be opening, and 0 indicating that the jaw should be closing). I implemented this algorithm using NumPy and pre-processed each sound byte to generate the assets which would be fed to the controller.
    • The Interface: In a perfect world, the hat would be wearable and would react to the user's speech, but given that I had a lot of other things on my plate at the time, I made the decision to trade a bit of the "wow" factor for a more practical CLI application. The user could enter their name (using a provided keyboard and monitor, which meant that the hat couldn't be worn), and if there wasn't an exact match they would be presented with a few close suggestions from the actual guest list that they could choose from. The hat would then hem and haw (a random number of times, selecting from a random set of "thinking" statements each time) before announcing which of the four tables the user was assigned to.
    • The Controller: This is arguably the fanciest part. When an audio file was to be played, the pre-processed data stream associated with it would be retrieved and fed to the hardware using RPi.GPIO to control the signals fed to physical wires. I set it up so that the jaw's opening angle was constrained to 30 degrees, and logic within the controller prevented any commands which would exceed that limit.
  • Mechanical Engineering: This project came with a physical jaw driven by a motor. Rather than try and MacGuyver an existing solution, I worked with Benjamin Mercer (Mercer Solutions Inc.) to model, measure, and machine 0.5"x2" steel rod into two nested arcs which were then attached together with washers and bolts before being connected to the motor. The motor directly controlled the outer jaw, and the inner jaw was made static and attached to a frame/enclosure we also constructed ourselves. The criteria for selecting the motor were power constraints (i.e. ensuring that it would be able to run off of power supplied by the Raspberry Pi), bi-directional capacity (so that the jaw could open and close to specific thresholds without having to complete a full rotation), and safety. It had to be powerful enough to move despite resistance from the fabric or minor external obstructions, but not so powerful that it would cause damage if it happened to close on a curious finger during the event. The latter concern was explicitly tested before and after assembly -- just in case.
  • Sewing and Animatronics: Then it came time to put everything together. The design and construction were all tested in stages, but the end result was the Raspberry Pi running the app being hooked up to an independent power source and the external monitor. The keyboard was wireless, connected via a bluetooth dongle plugged into the Pi's USB port. I then mapped the GPIO ports of the Pi to the motor's driver (TB6612) using a breadboard before securing all of them parts in the enclosure that I set up inside the jaw. To save time, the shell of the hat was purchased online, but I carefully cut the mouth out and manually sewed the jaw in place such that it would move the fabric with it when it spoke. The enclosure was then sewn directly into the hat as well so that the internal components would be contained while it was in operation.
